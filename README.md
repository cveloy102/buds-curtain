# Xiaomi Buds 5 — тестовая сборка для POCO F7

Цель: показывать нижнюю карточку при открытии Xiaomi Buds 5 и скрывать при закрытии кейса. Целевая система: HyperOS 3.0.303.0 / Android 16.

Текущая версия: **0.6.6**. Результаты тестов: [OBSERVATIONS.md](OBSERVATIONS.md).

Готовая APK: [скачать Buds Curtain 0.6.6](https://github.com/cveloy102/buds-curtain/releases/download/v0.6.6/BudsCurtain-poco-f7-test.apk). [Страница релиза](https://github.com/cveloy102/buds-curtain/releases/tag/v0.6.6). Для скачивания войдите в GitHub под аккаунтом с доступом к приватному репозиторию.

## Что готово

- Нативное Android-приложение, выбор уже сопряжённых наушников, разрешения Bluetooth и окна поверх других приложений.
- Плавающая карточка с изображением Graphite Black Buds 5 и кейса, зарядом в порядке **левый — кейс — правый**. При движении вниз она следует за пальцем: короткий жест возвращает её на место, длинный скрывает до следующего открытия.
- Для Buds 5 карточка показывается, когда свежие сигналы Fast Pair подтверждают, что оба наушника заряжаются в кейсе. Подтверждения левого и правого могут прийти в соседних пакетах. Если один или оба вынуты, карточка скрывается и сигналы с одним наушником не вызывают всплытия.
- В разделе «Внешний вид» доступны «Как в системе» (по умолчанию), «Светлая» и «Тёмная». Тема меняет экран приложения и уже открытую карточку сразу; системный режим следует теме HyperOS.
- Иконка приложения показывает один Graphite Black Buds 5 на светлом круге; системные тематические иконки используют одноцветный силуэт.
- Анимация перемещает полностью непрозрачную карточку через `translationY` на аппаратном слое: 420 мс на появление, 320 мс на уход. При быстрой смене состояния движение продолжается из текущего положения. Для окна запрашивается 120 Гц, если этот режим доступен и выбран системой.
- Фоновая служба: события Bluetooth-подключения и BLE-сканирование. На POCO F7 с Android 16 служба работает без карточки Buds Curtain в шторке уведомлений. Android по-прежнему показывает службу в списке активных приложений.
- После закрытия карточки её окно удаляется из системы. Скрытая карточка больше не занимает область касаний в других приложениях.
- Разбор трёх батарей, флагов зарядки и команд показать/скрыть из [Fast Pair](https://developers.google.com/nearby/fast-pair/specifications/extensions/batterynotification), включая заголовок 0x10, зафиксированный на выбранных Xiaomi Buds 5. Свежая проверка на POCO F7 дала L/R/кейс **100/100/64**, значения совпали с системными Bluetooth metadata. В карточке порядок соответствует рисунку: **Левый — Кейс — Правый**.
- Фильтр BLE и проверка адреса выбранного устройства. Свайп скрывает карточку до следующего открытия или перерыва в сигналах.
- Локальный журнал изменений заряда. Расширенная диагностика дополнительно записывает BLE-пакеты выбранного адреса и ближайшие Fast Pair-пакеты. Данные не отправляются по сети.
- На главном экране показаны последние значения и давность сигнала. Единственные сопряжённые Xiaomi Buds 5 выбираются автоматически.

## Ограничения тестовой версии

Получение заряда и цикл закрыть/открыть проверены на POCO F7; пользователь подтвердил работу. При отсутствии данных заряд показывается как `—`. Для выбранных Buds 5 карточка появляется по команде Fast Pair показать при свежем подтверждении зарядки обоих наушников и известном заряде кейса. Отдельные подтверждения объединяются за 6 секунд. Карточка скрывается по полной команде скрыть, при потере этого состояния, отключении Bluetooth или отсутствии свежих сигналов 8 секунд. Это состояние рекламы наушников, а не отдельный физический датчик крышки или нахождения в ухе. При выключенном экране приложение не показывает новое окно. Сканирование BLE оставлено в прежнем экономном режиме. При ошибке сканирования служба повторяет запуск с паузой; экран приложения показывает состояние восстановления Bluetooth. Ограничения фоновой работы HyperOS могут потребовать разрешить автозапуск и снять ограничения батареи через настройки приложения. Длительная работа в фоне пока не проверялась.

Эксперимент FD2D из 0.2.0 удалён: для полученных пакетов достаточно пассивного BLE. Переподключение к служебному каналу наушников не требуется.

## Как проверить на POCO F7

1. Установить [тестовый APK](https://github.com/cveloy102/buds-curtain/releases/download/v0.6.6/BudsCurtain-poco-f7-test.apk) на телефон и открыть приложение. Android может попросить разрешить установку из выбранного источника.
2. Выдать «Устройства поблизости» и разрешить показ поверх других приложений. Проверить, что выбраны **Xiaomi Buds 5**.
3. Выбрать тему в разделе «Внешний вид». Нажать «Показать карточку для проверки дизайна». Проверить, что она поднимается и через 5 секунд уезжает вниз. В демонстрации без свежих данных показываются примерные значения 100/64/100 с подписью «Пример отображения».
4. Нажать «Запустить наблюдение».
5. Держать экран включённым, кейс рядом с телефоном, оба наушника внутри. Открыть на 10 секунд, закрыть на 10 секунд; повторить три раза. Сравнить три значения со штатным отображением заряда на телефоне.
6. Проверить жест при открытом кейсе: карточка следует за пальцем, после короткого движения возвращается, после длинного скрывается до следующего открытия. Затем вынуть один наушник и оставить второй в кейсе: карточка должна уехать вниз и не всплывать снова. Проверить поведение при заблокированном экране.
7. Если карточка не реагирует, включить расширенную диагностику, повторить тест и прочитать локальный журнал через ADB или кнопку копирования. Журнал содержит Bluetooth-адреса; перед передачей можно удалить лишние строки.

После проверки выключить расширенную диагностику. Наблюдение можно остановить отдельной кнопкой.

## Сборка из исходников

Открыть папку в Android Studio и выполнить `assembleDebug`. Проект использует AGP 9.4.1 и SDK 37.0 для сборки, целевая версия приложения — Android 16 (API 36), минимальная — Android 12 (API 31). Готовый APK после сборки лежит в `app/build/outputs/apk/debug/app-debug.apk`.

Проверки без Android: с Java 17+ выполнить `javac -d build/checks app/src/main/java/com/budscurtain/FastPairBattery.java app/src/main/java/com/budscurtain/CurtainState.java app/src/main/java/com/budscurtain/BudsDockEvidence.java checks/FastPairBatteryCheck.java checks/CurtainStateCheck.java checks/BudsDockEvidenceCheck.java`, затем запустить классы `com.budscurtain.FastPairBatteryCheck`, `com.budscurtain.CurtainStateCheck` и `com.budscurtain.BudsDockEvidenceCheck`.
